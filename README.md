## 📖 English Description

**Timer, Stopwatch & Alarm Pro** is a complete time management tool built with HTML, CSS, and JavaScript. It features three main modes with smooth animations, sound alerts, and high precision timing.

### ✨ Features

| Mode | Features |
|------|----------|
| **⏲️ Timer** | Countdown with centisecond precision, visual progress ring, color-coded warnings (green → orange → red), beep alerts, screen flash when time's up |
| **⏱️ Stopwatch** | Count up with centisecond precision, lap recording, lap history list, maximum 99 minutes |
| **⏰ Alarm** | Set specific time (hour/minute), shows current time, rings with beep and screen flash at set time |

### 🎮 Common Features
- 🔊 Mute button to disable all sounds
- 🎨 Smooth circular progress animation
- 📱 Fully responsive design (works on mobile & desktop)
- 💻 Pure HTML/CSS/JS - no external dependencies

## 📖 توضیحات فارسی

**تایمر، کرونومتر و آلارم حرفه‌ای** یک ابزار کامل مدیریت زمان است که با HTML، CSS و جاوااسکریپت ساخته شده. این برنامه سه حالت اصلی با انیمیشن‌های نرم، هشدار صوتی و دقت بالا دارد.

### ✨ ویژگی‌ها

| حالت | ویژگی‌ها |
|------|----------|
| **⏲️ تایمر** | شمارش معکوس با دقت صدم ثانیه، حلقه نمایش پیشرفت، هشدار رنگی (سبز → نارنجی → قرمز)، بیپ هشدار، چشمک زدن صفحه در پایان زمان |
| **⏱️ کرونومتر** | شمارش رو به جلو با دقت صدم ثانیه، ثبت دور (Lap)، نمایش لیست دورها، حداکثر ۹۹ دقیقه |
| **⏰ آلارم** | تنظیم زمان مشخص (ساعت/دقیقه)، نمایش ساعت فعلی، زنگ با بیپ و چشمک زدن در زمان تنظیم شده |

### 🎮 ویژگی‌های مشترک
- 🔊 دکمه قطع صدا برای غیرفعال کردن همه صداها
- 🎨 انیمیشن دایره‌ای نرم
- 📱 طراحی واکنش‌گرا (کار روی موبایل و دسکتاپ)

## 🛠️ How to Use / نحوه استفاده

### English:
1. Select mode: Timer / Stopwatch / Alarm
2. For Timer: Set minutes & seconds → Click Start
3. For Stopwatch: Click Start → Use Lap to record times → Reset to clear
4. For Alarm: Set hour & minute → Click Set Alarm
5. Use Mute button to silence all sounds

### فارسی:
1. حالت مورد نظر را انتخاب کنید: تایمر / کرونومتر / آلارم
2. در تایمر: دقیقه و ثانیه را تنظیم کنید → دکمه شروع را بزنید
3. در کرونومتر: دکمه شروع را بزنید → برای ثبت دور از دکمه Lap استفاده کنید → Reset برای پاک کردن
4. در آلارم: ساعت و دقیقه را تنظیم کنید → دکمه Set Alarm را بزنید
5. برای خاموش کردن صداها از دکمه Mute استفاده کنید
